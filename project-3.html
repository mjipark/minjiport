Project Three

Experimental Site →

Three.jsViteCSS
Live ↗ GitHub ↗

A personal experiment in scroll-driven storytelling and WebGL-flavored transitions.

Overview

A self-directed project to push scroll-based narrative further than a typical marketing site allows — built with no client and no deadline, purely to test how far a single scrollbar can carry a story.

Role & Tools

Solo concept, design, and build. Three.js for the WebGL scenes, Vite for a fast local dev loop, plain CSS for everything outside the canvas.

Highlights

  • Choreographed scroll-linked 3D scene transitions without relying on a heavy animation framework.
  • Kept the non-WebGL parts of the page in plain, accessible HTML/CSS so the experiment stays usable.
  • Used it as a testbed for performance techniques later reused on client work.
