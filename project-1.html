LUMA REEF reimagines journaling as an underwater world that grows with you.

Overview

Built with Three.js, it turns each diary entry into a living reef — corals bloom, colors shift, and the water's mood changes based on real-time sentiment analysis powered by the Claude API. A fish companion swims alongside you, offering a gentle chat presence that responds to what you write.

Role & Tools

Built solo for a Data & AI course. Three.js for the reef and underwater scene, the Claude API for real-time sentiment analysis, and scroll-triggered animations on the About page to unfold the reef's world as you explore.

Highlights

  • Turned each diary entry into a living reef — corals bloom and water color shifts with real-time sentiment analysis.
  • Built a fish companion with a gentle chat presence that responds to what you write.
  • Still a work in progress — currently being refined and expanded.
